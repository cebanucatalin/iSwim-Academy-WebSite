# iSwim Academy Website

A static multi-page website created for **iSwim Academy**, a children's swimming academy in Chișinău, Republic of Moldova.

The project focuses on a clean, modern and responsive presentation of the academy's services, pricing, contact information and swimming-related content.

## 🌐 Project

**Project type:** Static website  
**Brand:** iSwim Academy  
**Location:** Chișinău, Republic of Moldova  
**Languages:** Romanian  
**Deployment:** Suitable for GitHub Pages

## 🛠️ Technologies

- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Iconify
- Responsive web design

The project includes a local Tailwind CSS browser bundle and local Iconify JavaScript bundle, so the website can work without requiring a build step or a Node.js project setup.

## 🚀 Running the Website

This is a static website and does not require a backend server.

You can open the relevant `index.html` files directly in a browser.

For local development, using a VS Code extension such as **Live Server** is recommended because it provides automatic browser refresh and a local development server.

## 🌍 GitHub Pages

The project can be deployed using GitHub Pages.

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the appropriate folder.
5. Save the configuration.
6. Wait for GitHub Pages to publish the website.

Because this is a static project, no backend or database is required for basic hosting.
